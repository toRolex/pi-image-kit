验收代码为 `f4517bb056a5459ad53c484d9c5f57d6ce678b80`。宿主为 Pi `1.1.0`。图像模型固定为 `gpt-image-2.5`，服务使用用户提供的配置。

用户确认了费用、联网和合成提示词、合成图片的发送范围。验收使用新 Pi 会话与隔离配置，没有加载旧同名 extension。没有使用私人图片，也没有把凭据、私有端点、会话原文或生成图提交到仓库。

临时验收 extension 限制最多四次图像工具调用，并禁止 shell、CLI、模型切换和失败后自动重试。本次观察到三次成功的 `image_generate` 调用。没有使用第四次额度。工具调用账本不是网关内部请求或计费审计。

## 实测结果

| 项目 | 实际操作 | 结果 |
| --- | --- | --- |
| 自然语言发现 | 在新会话询问可用图像能力 | Pi 确认唯一 `image_generate`，说明生成、绝对路径编辑和 recent 输入 |
| 生成 | 请求透明背景、中央蓝色圆形 | 返回一个 PNG image content 和成功保存路径 |
| 绝对路径编辑 | 引用上一张原图，将中央主体改为绿色 | JSON 编辑路线成功，返回新 PNG 与路径 |
| recent 续改 | 不提供路径，使用 `num_last_images_to_include: 1` 将上一张改为红色 | 同一会话续改成功，返回新 PNG 与路径 |
| 透明像素 | 用 Pillow 只读检查三张实际输出 | 三张均为 RGBA，四角 alpha 均为 0 |
| 清洁生产包安装 | 打包、解包至无 `node_modules` 的目录，在独立 profile 执行标准 `pi install` | 已安装 Pi 1.1.0 宿主可加载唯一 active 工具及完整 skill，不向包内链接开发依赖 |

三张输出均为 `1536 × 1024`。逐张检查的中心 RGB 如下。

| 阶段 | 中心 RGB | 全透明像素数 |
| --- | --- | --- |
| 蓝色生成 | `[0, 0, 251]` | 1,363,004 |
| 绿色路径编辑 | `[8, 246, 4]` | 1,360,830 |
| 红色 recent 续改 | `[252, 1, 0]` | 1,362,610 |

这些像素结果证明本次输出有真实透明区域，而不是仅收到 `background: transparent` 的服务声明。结果只覆盖当前服务与 `gpt-image-2.5` 的组合，不承诺其它模型或网关的透明效果。

## 证据与限制

脱敏工具调用账本、参数与结果记录、像素检查脚本、安装探针及原始合成输出保留在本机。会话导出保留在私有目录，只用于核对本次验收，不进入公开包。

清洁生产包测试复用已经安装的 Pi 宿主。它不证明全新机器安装 Pi，也不证明全新 checkout 的 pnpm 开发依赖安装通过。后者仍受此前 release-age 和 dependency build scripts 策略阻塞，没有绕过或批准。
